# Slop 历史研究工具

2026-09-26 的三批研究已经结束。对应的旧报告、执行快照、调用记录和冻结请求已从当前目录清理，完整材料保留在 Git 历史中。当前机制见 [中文正文质量机制](../../doc/architecture/language-quality.md)，阶段状态以 [路线图](../../doc/roadmap.md) 为准。

## 历史命令

固定研究批次的十五个 Python 命令、旧研究测试和三个依赖旧接口的 Java 辅助程序已删除。它们的实现与输入材料可从 Git 历史按同一版本查询。

需要查阅历史结果时，通过 Git 查询清理提交之前的原始脚本和材料，按同一版本成套阅读。不要用当前源码重新生成旧快照，也不要根据旧脚本重发历史未知请求。新的研究按独立任务安排输入、验证和预算。

## 保留的离线工具与材料

`SlopStudy.java` 使用当前规则检测器，对显式输入的 JSON 语料执行离线分析，不访问网络或数据库。现行测试、作者校准和待审阅材料继续保留。

研究目录中保留的语料、任务、协议和校准材料继续供现行夹具、机制说明及作者审阅引用。作者待确认的原文、候选和完整比较稿保留在文档中心列出的审阅入口。
