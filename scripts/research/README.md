## 已退役的 Python 命令

本目录的 Python 命令属于上述固定研究批次，现已停止作为命令行入口使用。直接执行会在导入依赖、读取数据、创建文件、登录或访问服务之前返回退役说明及非零退出码。旧实现保留供阅读；不再提供重新冻结、登录、调用、导出、复验或重建历史账本的执行步骤。`test_slop3.py` 同属该批次的旧研究测试入口。

需要查阅历史结果时，通过 Git 查询清理提交之前的原始脚本和材料，按同一版本成套阅读。不要用当前源码重新生成旧快照，也不要根据旧脚本重发历史未知请求。新的研究按独立任务安排输入、验证和预算。

## 保留的离线工具与材料

`SlopStudy.java`、`SlopProbes.java`、`Slop2Prompts.java` 和 `Slop3Prompts.java` 保留源码，分别用于离线观察、探针和显式输入的提示组装；它们不发送模型请求。使用时需要与当前后端接口兼容的编译环境和明确输入，旧报告不作为当前实现的验证结果。
