# 小说与大纲

## 故事与角色

“小说管理”用于查看、创建和删除故事。进入“工作台”后，可在“故事构思”和“故事管理”中继续编辑故事卡。

- “故事构思”：根据标题、类型、基调和核心想法生成故事与初始角色草稿。
- “故事管理”：维护标题、简介、类型、基调、状态、已发布世界观关联和角色卡；角色可单独新增、编辑和删除。
- 删除故事会影响其关联内容。删除前先确认不再需要该故事下的大纲和稿件。

## 大纲编排

在工作台的“大纲编排”中：

1. 选择故事，点击“新大纲”，填写名称并确认创建；进入页面本身不会自动创建数据。
2. 在“当前大纲”中切换不同方案，或删除不再需要的大纲。
3. 按章节生成场景，或直接编辑章节标题、摘要和场景内容。
4. 需要时为大纲选择已发布世界观。
5. 点击“生成下一章”时核对章节编号、世界观和项目积分提示，再确认生成。
6. 使用“保存修改”提交本轮手工调整。

场景是正文生成和质量分析的最小工作单位。先完成场景目标和摘要，生成正文时会得到更稳定的上下文。

## 与助手讨论并整理资料

点击工作台顶部的“故事讨论”打开面板。只要已有故事就能开始讨论，不必先创建稿件或正文；切换故事设定、大纲编排等标签时可继续同一话题。

1. 新建话题并填写便于辨认的名称，例如“主角与对手的关系”。可以切换已有话题；刷新或切换工作台标签后，最近使用的话题和已完成答复仍保留。
2. 与助手讨论人物、故事方向或场景安排。助手给出的整理建议仍是讨论内容，不会自动修改资料，也不会因为显示建议额外发起一次生成。
3. 准备整理时，先检查面板头部的当前故事和“目标大纲”。整理章节场景前须选择一个大纲；没有大纲也可以整理角色卡。若目标有未保存修改，先保存成功或取消编辑；普通讨论只参考已保存资料。
4. 点击“整理为资料提案”，开始一次新的生成任务。按角色、章节或场景逐项查看“字段前后对照”；展开“查看完整候选并手动修改”调整字段，先点“保存候选”，再“采纳”需要的项目。保存候选只保存待审阅版本，不修改正式资料。新章和它的首批场景作为一个整体采纳。
5. 采纳后回到原角色卡或大纲页面查看并继续编辑。助手只更新所选资料，新增章节或场景追加在末尾，不删除或调整现有顺序。

手工修改候选后，即使折叠提案、切换话题或故事，回到同一工作台仍能找回未保存内容。整页刷新会丢失尚未保存的候选编辑，刷新前请先点“保存候选”。若候选已在别处更新，原编辑仍保留供比较，不能直接覆盖新修订。

故事级资料会供同一故事或大纲下的稿件使用，不是某个正文分支的私有修改。助手默认查看故事资料、角色、所选大纲和当前话题，不会自动通读全书正文。

如果某项提示资料已变化，先比较当前值与候选，再重新整理；系统不会覆盖后来保存的内容，其他未冲突项目仍可采纳。新增项采纳后没有自动撤销按钮，可通过原有编辑入口继续维护。更新项只有在当前资料仍与本次采纳结果一致时才可撤销；后续已改动的资料不会被撤销覆盖。

仍待采纳的提案可以“继续打磨”，填写新要求后产生一个关联旧提案的新候选，旧稿保留。打磨期间沿用原提案的目标资料，目标大纲选择固定；清除打磨状态后可另选大纲讨论。已采纳、拒绝或撤销的项目需要基于当前资料重新讨论和整理。

讨论、整理和继续打磨是分别计费的生成任务；采纳、拒绝、手工编辑候选及撤销不调用模型。任务失败或结果尚未确认时查看原任务状态，不要把恢复与重新生成混为同一操作。

如果作品启用了人物知情控制，保存角色卡或大纲不代表角色已经知道其中的秘密，也不代表本场计划已确认。仍须在原有知情和场景计划入口中决定哪些内容可用于生成。

## 进入写作

在“小说创作”中依次选择故事、大纲和稿件。没有大纲或稿件时，使用左侧明确的命名创建入口；仅打开页面不会隐式生成空记录。一个大纲可以保留多份稿件，用于不同版本或写作方向。选择场景后，编辑器会加载该场景的正文。
