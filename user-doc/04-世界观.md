# 世界观

## 创建与编辑

在“世界构建”中可以查看已有世界、新建草稿或打开编辑器。世界编辑器包含基础信息和模块字段：

- 基础信息：名称、标语、主题、创作意图和备注。
- 模块字段：按后端定义填写世界规则、环境和其他设定。
- 字段精修：保存当前编辑后，选择单个字段并填写精修要求。AI 候选可以继续编辑，查看前后差异后采纳到当前输入，再保存世界。关闭窗口会放弃候选；空结果会保留原文，不自动重试。

保存一次提交基础信息和模块。保存期间继续输入的内容会保留为未保存编辑；离开页面时会提醒处理。如果其他窗口已经更新同一个世界，当前输入会保留并显示冲突，需先对照最新内容处理，不能直接覆盖。

列表中的已填写字段比例只表示当前定义字段的填写情况，不代表世界的质量或必须达到的创作目标。尚未加载或读取失败时，不会以 0 或 100% 代替真实结果。

保存不会自动改写故事正文。当前阶段，后续生成仍可能读取世界的最新内容；草稿、发布版本和小说固定版本将在后续阶段交付，状态以[路线图](../doc/roadmap.md)为准。

## 预检与生成

1. 保存已知设定。
2. 使用“备注”记录来源、约束和后续事项；当前备注也可能进入后续生成的世界上下文。
3. 点击“预检/发布”查看尚无内容的模块和待生成模块；只填写部分字段的模块目前也可发布。
4. 无论是否需要生成模块，都必须再次确认才会发布；需要生成时会提示项目积分消耗。
5. 后台任务失败或中断时，通过原任务恢复，保留原请求身份。结果完成后，当前世界会收到更新提示；如果还有未保存编辑，先对照服务器结果处理，页面不会直接替换输入。

任务中的“查看已生成内容”可只读查看、复制已经返回的字段，包括尚未写入世界的结果；不会再次调用 AI。若任务期间世界已被其他编辑修改，先查看保留的输出与当前设定，不能沿旧基线直接覆盖。网络恢复后可通过“刷新任务状态”读取原任务的状态。

世界观完成后，可在故事构思、大纲或稿件中选择它作为上下文。删除仅对草稿世界开放；已发布或已被使用的世界应先确认影响范围。
