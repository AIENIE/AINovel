# 素材、知识库与图谱

## 素材库

素材库提供三个标签页：

- “素材列表”：按标题或标签筛选当前素材，并可通过操作菜单编辑或删除自己的素材。
- “手动创建”：录入标题、类型、概要、正文和标签。
- “批量导入”：上传 TXT 文件并等待导入任务完成。

已审核素材可用于工作台检索和正文生成上下文。向量服务不可用时，系统会保留关键词检索；结果相关性可能下降但基本检索仍可使用。

普通用户可编辑和删除自己的素材。审核、重复候选、素材合并和引用查询属于平台治理能力，只在管理员后台提供。导入任务超过自动查询时限时会显示“仍在处理中”，可继续查询，只有服务端返回完成后才会显示解析成功。解析完成后素材仍会以“待审核”状态出现在列表中，等待管理员治理，不代表解析任务仍未完成。

## 知识库

工作台“知识库”用于维护 Lorebook 条目：

1. 选择故事。
2. 创建、编辑、删除或批量导入条目。
3. 设置条目的分类、优先级、Token 预算和启用状态。
4. 使用实体提取和上下文预览检查条目是否适合当前场景。

## 知识图谱

“知识图谱”按当前故事展示知识库实体和关系。可按关键词查询、创建或删除关系，并在需要时同步图谱。图谱用于辅助理解设定关联，不会自动改写故事正文。删除节点会同时删除对应的 Lorebook 源条目及全部关系，确认前请检查影响范围。
