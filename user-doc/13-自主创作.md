# 自主创作与打磨

在工作台打开一个场景，先保存当前正文，再点击“自主创作”。写明希望起草或修改的目标，选择快速/精雕及允许使用的检查，设置最高费用、项目积分和调用次数。先预览，再统一确认模型和报价。只做作者问答时可以读取未保存草稿，但不能修改正文。

AI 会自行决定何时查世界、读取前文、起草、检查或继续修改。世界内容按需逐块读取，不会预先加载全文。“必须纳入”的资料要完整读完；放不下时会要求调整。“排除”针对所选来源，其他已允许资料可能仍包含相同事实。

执行记录区分“模型提出的工具请求”和“工具真正返回的材料”。可展开首步发送内容、实际来源和检查报告；世界版本固定为启动时的小说绑定版本。未读到某项内容不代表它不存在。

每个候选独立保留，可以完整对照或切换差异。关闭面板或刷新后可继续查看。生成期间可以继续输入，返回结果不会替换新输入。采纳前须先保存并核对原稿；版本或来源变化后，旧候选保留供比较。

暂停会等待当前调用结束；取消不会撤销已产生的费用。达到额度或输入容量时停止，不会自动提高额度。需要补充关键设定时可在面板答复；答复只服务本任务，不自动成为世界事实或人物知情。

每次请求返回完整结果，面板逐步显示执行进度。人民币模型成本与项目积分分开显示；待对账的预留不当作零费用。未配置协调/修订步骤，或服务没有明确提供原生工具预算组合能力时，系统会阻止调用。

“模型步骤”包含尚在准备的步骤，不代表已经向供应商调用。预算准备失败会明确提示本步未发送，并保留原任务；只有额度确实用完才显示预算耗尽。不要据步骤数量或没有结果推断费用，已结算费用和待对账预留分别核对。

当前入口面向单个场景与作者问答。逐章确认、整书项目与旧稿接续的排期和验收边界以项目路线图为准；模型检查不替代作者判断。
