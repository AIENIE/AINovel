## 交付内容

- 只读质量门原样返回候选；普通生成、评测生成及剧情候选采纳不再自动 Slop 改稿。剧情采纳只保存审阅稿，没有再次审校的费用。
- 新手动 Slop 冻结正文、分支、版本、投影、哈希与完整提示。坐标错误只允许唯一精确引文重定位；没有可靠来源的历史报告不补造来源。
- 本地线索与语义判断分离，确认问题才参与最终风险；正常对白和推理不能凭局部词面判错。全文输入超限零发送，显示未检查。
- Slop 语言问题复用现有候选、一次复核、作者接受／拒绝／撤销及幂等流程；输出残留与文风只给证据和建议。
- V40 追加 Slop 审阅快照，V41 扩展既有验收金额账本。旧迁移未改；不建立第二套候选处置表。
- local CNY 路径使用现有 canonical proto 的预算能力、报价、凭据和状态查询，单次供应商尝试。金额与项目积分分别记账，未知费用保留最高预留。

精雕提示、叙事目标、重复算法、密度阈值、影子权重、剧情诊断及长稿巡检未扩展。
