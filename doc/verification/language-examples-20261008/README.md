# 语言示例接入：实际验证记录

2026-10-08。**v3 工程接入已实现，语言效果未通过，完整本地 L4 未完成。** 不发布、不解除 H2/G2 门槛，不把小样本判断写成生产准确率。作者反馈优先于模型复核结论。

## 作者判断与语言结果

- **S5：**两组诊断都指出“可‘找’这个动作还在，不拉也在”的生硬抽象与所指不明。带示例候选改为“可去找寄信人的念头还在，不用她刻意去想，也在那里”。作者明确认为比完全不可接受的原文好，但候选仍不太好；细节待作者另行说明。不能据此标为语言通过，也没有单独确认原意。
- **S6：**两组都漏掉首段持续压缩的问题；带示例仍没有给出对应整段诊断。候选目标是调用前选定的首段，不能把生成了改写当成诊断已经命中。带示例候选将“她蹲下去翻”写成“她蹲下去翻洗漱包”，作者确认“至少这个示例上，没有改变”，撤回助手对此例动作对象的疑虑；不扩大为所有补足对象均安全。表达效果尚未单独确认。
- **新问题场景：**两组都报告两处主语省略，带示例指出后半段无法确定行动者。**正常边界：**仅规则无问题；带示例仅报一条 OBSERVATION，针对未标明说话人的对白，没有把短句判为 LANGUAGE 错误。该构造场景确实没有交代另一说话人，不能作为完全无歧义的正常样本。
- **D2 真实业务流程：**定位连续原文“核完最后一行，划掉一个名字，把表推到桌子中间。”并说明赵岑、许安均可能是行动者；修订返回 NEEDS_CONTEXT，未猜成某个人或两人共同完成，没有复核调用。
- 三份实际复核全部给出 language/meaning PASS，但 S5 作者仍未接受，说明复核 PASS 不能代替作者验收。S5 仅规则候选结果未知，没有为了配齐样本重新推理。
- 16 份初稿均有确认结果；带示例组仍有动作与发现硬切，例如出门前快速稿中单列“是一张戏票。”。初稿 650–850 汉字范围：仅规则 5/8、带示例 2/8；长度仅是场景要求检查，不能作为自然度评分。没有进行作者盲评，不计算胜率或宣称示例改善效果。

可直接审阅：[两组候选完整上下文与作者反馈](AUTHOR-REVIEW.md)、[诊断完整输入和输出](DIAGNOSIS-COMPARISON.md)、[16 份初稿](GENERATION-COMPARISON.md)、[作者原话](author-feedback.json)。S5/S6 与 C—F 是校准材料；新构造场景也仅支持本地试用判断，不计入 G2。

## 实现范围

结构化 [v3 资源](../../../backend/src/main/resources/quality/language/zh-naturalness-v3.json)与[规则](../../../backend/src/main/resources/quality/language/zh-naturalness-v3.txt)按任务注入 C、修正后的 D、E、F；A/B 未进入请求。D1 是依据作者意见作出的最小修订，没有冒称逐句确认；E/F 保留试用状态。生成只读取可接受正文与事实，诊断读取完整原文和判断依据，修订/复核读取改写及内容变化边界。

[LanguageStandard](../../../backend/src/main/java/com/ainovel/app/quality/language/LanguageStandard.java)保留 v1/v2 渲染和输出解析，v3 使用固定规则及示例哈希。生成任务创建时冻结版本、开关和哈希；诊断绑定报告版本，修订及复核沿用报告。缺失或改变的版本不能恢复为最新版重新扣费。生成快照以四个标量保存版本、哈希与开关；该最终快照清洗修正由单元测试验证，已付费生成不回填这四项历史字段。

[LanguageQualityService](../../../backend/src/main/java/com/ainovel/app/quality/language/LanguageQualityService.java)保存 NEEDS_CONTEXT 原因，候选与复核为空，重复请求复用原 operationId；采纳入口拒绝该状态。前端显示原因和未生成建议的说明，不显示采纳按钮。已有补丁的版本、分支、正文校验和撤销继续沿用，无数据库迁移。接口见[质量 API](../../api/v2-quality.md)。

诊断容量按实际版本的完整规则、示例、正文与邻段计算；不够时显式记录跳块。真实诊断输入没有注入隐藏资料标记，见[38 次请求隔离核对](h2-request-isolation.json)。这是本批构造标记检查，不等于任意隐藏信息均已证明隔离。快速和精雕真实 H2 生成及后台检查都成功，保存正文后登记检查，不等待诊断才能交付正文。既有盲测提示未改。
