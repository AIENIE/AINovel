## 固定协议

- 唯一预算编号：`language-20261007-v1`；40 次模型业务调用、120 次供应商尝试，包含附带调用和重试。账本只递增，不能清零或补充。`reserved_provider_attempts` 是保守预留上界，不能写成实测发送次数。
- 本地模型键固定为 `deepseek-flash`。实际生成使用 16 份 [v2 冻结提示](frozen-prompts-v2.json)，来自实际 `PromptAssemblyService`：4 个独立构造场景 × 快速/精雕 × 原提示/新增规范。它们不是 S5/S6 历史生成提示。[v1 冻结文件](frozen-prompts.json)仅作准备，没有用于生成对照。场景要求、角色可用信息、精雕采样 UUID 及约束均保存；同组唯一提示差异是规范消息。未控制供应商内部随机性，小样本不能归因成稳定准确率。
- 初稿对照通过 `/v1/ai/chat` 隔离重放，不附带其他质量调用；使用稳定幂等键保留请求结果。候选编辑效果另行报告。
- 诊断使用 S5/S6 完整正文、完整 fast:3/fast:6、正常连续动作/简短对白、重复引文/实体/emoji，以及超过旧截断长度的整段长正文。后者包含人为重复，仅验证覆盖和尾部定位，不能当成正常小说的误报率样本。
- 生成最多 4 份局部候选，每份复核一次。模型复核不是作者确认。保留原文、完整候选、相邻段落、遗漏、误报、内容变化和不确定项。
- 仅在本地新建的“语言自然度本地验收 20261007”作品启用工作级开关。固定样例保存和普通编辑不应调用模型；无自动采纳。预发布与生产不在范围内。

## 供应商重试预检

对正在运行的 develop 网关只读检查，版本 `20261006003`，release ID `0e5284e9-b48a-4179-b6ee-8c0440004f3b`，镜像 `sha256:5bd691d1d39fcce83b10f9f098ecbe1e03ba0ff4c6b04f76aee6cdb093badd85`。

运行时文件及进程环境未设置 `AI_GATEWAY_FAILOVER_MAX_ATTEMPTS`。从运行中 `/app/app.jar` 提取对应 class 并使用 `javap -c -p` 核实：`GatewayManagedCallFailover` 的该配置默认值为 3；它通过 `ProviderRetryPolicy.managed` 调用供应商，使适配器内层只尝试一次。未受托管调用的 `ProviderRetryPolicy` 同样读取该配置，默认上限 3。本应用 [gRPC 客户端](../../../backend/src/main/java/com/ainovel/app/integration/AiGatewayGrpcClient.java)每次业务发送只调用一次 stub，没有额外应用重发循环。因此每次预留 3 次供应商尝试，总预留不超过 120。

## 实施中发现并修复的问题

隔离数据库测试发现：Hibernate 字节码增强环境下，从服务类直接修改实体字段，报告状态和候选更新可能未被脏跟踪识别，模拟仓库测试不能暴露该问题。已改为通过实体方法修改，并通过真实数据库中的状态、回滚、幂等和并发测试。

## v1 首轮校准失败，保留原始记录

前两次真实调用使用 `zh-naturalness-v1`。S5 [原始结果](pilot-v1-S5.json)命中完整问题句，但只解释“不拉”指代不明，没有明确解释“动作还在”的抽象化问题。S6 [原始结果](pilot-v1-S6.json)列出三项搭配问题，漏掉已确认的省略、压缩和硬切断句；还把“一样硬东西”误判为量词结构不成立。这两次不能记为语言效果通过。

保留 v1 规范和旧冻结提示；v2 在相同五个方向下补充“能猜懂不等于自然”、先逐段连读再检查措辞及独立构造的短小表达示例，不注入 S5/S6 故事。v2 复验也计入同一 40/120 账本，不另开预算。校准样例参与了规范修订，因此它们不是独立留出集；反例与新构造场景仍需单独检查。

浏览器启动及内置浏览器连接失败；本机可用内存曾不足 1 GB，类路径加载也明显延迟。`agent-browser` 的专用 Chrome/Edge 实例提前退出，内置浏览器在应用健康后读取已有本地页面仍超时，Chrome 扩展连接也报错。未关闭其他任务的浏览器或绕过 TLS。桌面、窄屏、浏览器刷新后的可视结果及控制台检查未完成，不能由组件测试或 API 结果替代。
