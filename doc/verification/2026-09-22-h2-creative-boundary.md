- 缺省/空白规范化为 null。编译器投影为 `NOT_PROVIDED`，表示没有作者提供的依据，不推断人物不知道，也不允许自行补出实施者。旧记录不复制 statement、uncertainty 或引文。

## 原文初评与停止原因

原稿均未经润色；段落编号见 `blind-B1-*.md`。严重设定问题不能由文风表现抵消。

| 优先级/类别 | 原文位置与问题 | 影响与建议 |
|---|---|---|
| P1 文本质量 / 关键物件连续性 | v4 FAST，B1 P3：“他的指头碰到内袋里一块硬纸片。不用掏出来，摸形状就知道是戏票”；v4 CRAFTED，P3：“抽出来，是那张戏票”，随后压在杯下 | 作者事实是戏票由赵熠保管；上下文正确隐藏了赵熠和袖袋，但模型把缺少位置依据当作可自行补齐，发明持有和移动。新版两种模式均未过核心设定门槛。后续应在现有作者计划中明确关键物件允许参与的动作范围，不能把真实藏处泄露给人物来修正，也不能凭空认定人物一定没有该物件。 |
| P1/P2 文本质量 / 未指定属性 | v4 FAST P1 使用“他”；v4 CRAFTED P1 使用“她”。B1 未提供性别 | 违反输入“未提供则使用姓名”约束，且两种模式互相不一致。缺省提示已传递，模型未遵守；不是前端自动补入性别。必要属性可通过现有作者背景模板补充，但不能据此宣称缺省行为已可靠。 |
| P2 表达确定性 | 错信 v4 CRAFTED P3：“信已经烧掉了，她清楚这一点” | 未再补出亲手烧信或目击经历，优于旧定向失败；但“清楚”强化了确定语气。段落处于人物内心，可解释为人物的确信，因此单列风险，不把它当作已证明的客观事实泄密。 |
| P2 输入范围 | B1 只批准整理衣物与安排早饭，没有批准接触戏票 | 普通动作可创作，但涉及关键载体的移动不应当作普通布景。建议将少数关键载体的操作范围列为作者计划的明确约束；不要求登记每只杯子或每句对白。该建议尚未作为新的产品数据模型实施。 |
| P3 文本质量 | 错信两稿都用分书、拿工具、拧螺丝、归位形成主体 | 动作清楚、结尾执行了整理计划，但情绪和选择增量弱，数段工具动作容易重复。后续输入可说明整理动作如何改变人物的下一步选择，避免只靠篇幅要求堆积动作。 |
