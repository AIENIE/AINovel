# AINovel 整改复审

复审日期：2026-09-27。范围为本分支代码与本地 L2、隔离 MySQL、PDF、依赖扫描证据；未接触业务数据库、付费模型或发布环境。原始三份审计结论没有改写。复审按审计编号逐项核对，关闭状态和修复提交见 [整改台账](tracker.md)。

## 重点复核

1. **正文覆盖**：编辑器保存任务固定稿件、分支、场景、正文和版本；响应按身份写回，切换后不覆盖当前草稿。当前场景的关键 JSON 使用严格解析，合并先保存工作副本快照，坏数据和冲突事务回滚。新场景表以 `(manuscript_id,scene_id)` 读写，单场景保存不重写旧档案列。相关 hook、分支、JSON 和隔离 MySQL 测试通过。
2. **权限绕过**：普通素材服务保留 owner 校验且更新 DTO 不含审核状态；治理入口及服务二次校验 `AUTH_LOCAL_ADMIN`。上传任务 owner 固定，孤立任务拒绝读取；内容版本变动使旧审核/索引/查重结果失效。权限和状态专项测试通过；真实身份提供方端到端会话验证仍属环境验收。
3. **晚到回调与重复执行**：AI 操作、导出及素材索引由数据库领取；执行 token、状态、租约和输入版本用于续租及写入仲裁。取消先提交后旧执行不能应用业务结果；结果先提交时取消返回已完成。隔离 MySQL 的双实例竞争和本地迟到回调测试通过。
4. **计费**：额度预留、模型结果持久化、结算和释放按短事务处理；重复结算和释放有状态与幂等键保护，结果不明进入恢复状态。测试覆盖重放与补偿；上游模型只以延迟/结果 stub 代替，不宣称外部恰好执行一次。
5. **迁移回退**：V1–V18 原样保留。V19–V23 新增表/列，维护入口逐稿回填及核对，坏 JSON 或校验记录不符阻断；隔离环境验证中断续跑和逆向重建。真实维护窗口、备份恢复和生产反向切换没有执行，必须遵循 [切换手册](storage-cutover.md)。

## 结果与保留条件

23 项按批准的 L2＋隔离专项范围取得本地关闭证据；六个代码提交还分别在临时 worktree 通过完整 Windows L2。完整 Windows L2 后端 479 项中 457 通过、22 条条件跳过、0 失败；前端 175 项通过，lint、类型检查及构建通过。条件跳过没有计入通过。容量样本覆盖 10/100/1,000 场景、1,000/10,000 资产、100/1,000/10,000 素材；测量值见 [验证记录](validation.md)，不能作为生产 SLA。

依赖扫描阻断项为 0，但 gRPC 客户端 shaded Netty 有一项有期限的服务端条件性例外与两项 Moderate 命中；例外适用性、到期日及官方依据见 [说明](security-exception-shaded-netty.md)。PDF 固定字体不覆盖所有 Unicode 字形，不支持字符明确失败。非关键旧页面尚有通用 `NetworkObject<any>`，关键稿件、分支、导出、任务和分页路径已加具体 Zod 契约。Linux CI shell 合成契约测试未在 Windows 原生环境跑通；扫描器单测、真实联网扫描和离线证据校验单独完成。以上均没有被标为真实环境验收。
