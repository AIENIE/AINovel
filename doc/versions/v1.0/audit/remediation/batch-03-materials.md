# 第三批：素材权限、审核、查重

对应 SEC-03、SEC-04、SEC-05、PERF-09。后台素材治理独立要求 `AUTH_LOCAL_ADMIN`，普通素材服务始终核对 owner；普通更新请求不接受审核状态。手动素材为 `MANUAL/approved`，上传素材为 `UPLOAD/pending`。内容版本变化使上传和来源不明素材重回待审，已驳回素材无法靠普通编辑恢复通过；旧上传任务通过结果关联回填 owner，孤立任务拒绝普通查询。上传任务和结果素材同事务创建，状态 GET 不推进任务。

查重仅由管理员显式启动，采用持久化版本指纹、倒排候选、单素材最多 50 候选、单任务最多 100,000 比较，支持取消与分页。达到候选或配对预算返回 `incomplete=true`；结果读取按素材当前版本过滤。待审列表使用数据库稳定排序和分页，默认 20、最大 100，仅投影标题、类型、摘要等轻量字段。

`MaterialGovernanceServiceTest` 覆盖普通用户/管理员边界、状态和孤立任务；`MaterialIndexBudgetTest` 覆盖索引边界。隔离 MySQL 容量测试将 100/1,000/10,000 条素材逐级增加，10,000 条时查重在测试用 100 对预算处明确停止并标记不完整；详情见 [统一验收记录](validation.md)。
