# 第五批：正文存储与列表规模

对应 PERF-06、PERF-07、MAINT-04。V21 建立 `(manuscript_id,scene_id)` 唯一当前场景表，稿件仍用乐观版本仲裁；统一 `ManuscriptContentService` 负责工作副本读写，历史快照、哈希与 H1/H2 证据保持原样。新模式单场景保存只更新目标行和稿件版本，工作台切至摘要列表、单场景读与紧凑保存响应；旧全稿接口保留兼容用途。新正文模式默认关闭，未回填稿件或降级旧应用直接访问时失败关闭。

独立维护入口执行 `backfill`、`verify`、`reverse`；按稿事务、可重入进度、数量/内容/哈希核对，坏 JSON、非法场景键、校验记录不一致阻断。V19、V20、V21、V22、V23 均为新增迁移，V1–V18 原样保留。后台资产、质量与待审素材列表采用数据库分页及不含正文 LOB 的投影，稳定排序包含 ID。工作台稿件、分支、导出、任务和分页结果在边界以具体 TypeScript/Zod 契约解析，异常响应不会进入编辑器状态。

隔离 MySQL 验证包括空库/V18 升级、回填中断续跑、坏数据阻断、校验记录篡改和逆向重建；10/100/1,000 场景的单场景写入检查了档案正文不被重写。切换步骤与回退条件见 [维护窗口手册](storage-cutover.md)，规模记录见 [统一验收记录](validation.md)。
