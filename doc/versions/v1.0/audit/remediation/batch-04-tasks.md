# 第四批：任务一致性与资源隔离

对应 PERF-02、PERF-03、PERF-04、PERF-05、PERF-08。AI 操作使用数据库原子领取、独立执行 token 与租约续期；进度、结果、业务应用受 token、状态和输入版本约束。取消和结果提交由数据库先后顺序仲裁：取消先成功禁止写结果，结果先提交则取消接口返回 `SUCCEEDED`。结果不明进入恢复状态，步骤调用使用稳定幂等键；不会假设上游因存在 request ID 就保证恰好一次。

世界生成与质量诊断拆分为输入快照及额度预留、事务外模型调用、短事务结果校验与应用。额度预留、结算、释放独立短事务，重放不重复计费，遵守既有取消计费契约。素材索引改独立 2 线程、16 队列 worker，单次 512 chunk/10 分钟/5 尝试，超限失败并保留旧有效索引；查询复核当前内容版本。

导出下载将最大 25 MiB 产物先从数据库复制到受控临时文件，再流式传输。默认 4 个全局、每用户 2 个下载名额，合计最多 100 MiB 暂存；超限 429，完成/断连/遗留文件有清理路径。相关 token、取消、重试、额度、索引与下载测试已加入；双实例竞争的隔离 MySQL 专项结果见 [统一验收记录](validation.md)。
