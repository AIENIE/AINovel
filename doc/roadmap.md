# AINovel 后续工作路线图

更新时间：2026-10-08。本文是后续开发状态、顺序、门槛和待决策事项的唯一权威入口。代码与当前接口文档仍是实现事实来源。

## 状态定义

- `已完成`：代码、迁移、文档和约定验证已交付。
- `待技术验证`：代码与文档已实现，但按开发者约定暂停，尚未执行测试、构建、部署或运行时验收。
- `验收中`：已开始约定验证且部分检查通过，但仍有明确的未完成项或外部环境阻塞；不得按已完成交付。
- `待运营验证`：功能已交付，但必须先积累真实数据。
- `门槛后立项`：指标达到前不得开始实现。
- `已确认后续`：方向已确认，仍受前置阶段阻塞。
- `独立排期`：不依赖主线门槛，可单独立项。
- `长期储备`：只有数据、模型或商业条件满足后才评估。
- `待决策候选`：仅保留证据，不代表承诺。
- `延迟完成`：需要大量人工收集、标注、评审或持续运营投入；除非用户主动点名，不进入执行队列。
