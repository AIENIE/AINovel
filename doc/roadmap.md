# AINovel 后续工作路线图

更新时间：2026-10-23。本文是后续开发状态、顺序、门槛和待决策事项的唯一权威入口。代码与当前接口文档仍是实现事实来源。

## 状态定义

- `已完成`：代码、迁移、文档和约定验证已交付。
- `待技术验证`：代码与文档已实现，但按开发者约定暂停，尚未执行测试、构建、部署或运行时验收。
- `验收中`：已开始约定验证且部分检查通过，但仍有明确的未完成项或外部环境阻塞；不得按已完成交付。
- `待体验验收`：工程实现与约定技术验证已交付，真实模型或可见页面体验尚未验收；不得据此宣称产品体验或文学效果通过。
- `待运营验证`：功能已交付，但必须先积累真实数据。
- `门槛后立项`：指标达到前不得开始实现。
- `已确认后续`：方向已确认，仍受前置阶段阻塞。
- `独立排期`：不依赖主线门槛，可单独立项。
- `长期储备`：只有数据、模型或商业条件满足后才评估。
- `待决策候选`：仅保留证据，不代表承诺。
- `延迟完成`：需要大量人工收集、标注、评审或持续运营投入；除非用户主动点名，不进入执行队列。

## 世界观专项分期（2026-10-23）

目标：世界既能独立创作，也能作为多部小说共用的设定来源。按 W1 → W2 → W3 → W4 → W5 逐期交付；本专项不解除 H2、H3–H6、G2、G1-A P1、Manual、SCORE 或 G6 的既有门槛。

### 已确认的产品边界

- 小说固定采用一个已发布世界版本；世界更新后，由作者查看差异并整版升级。新绑定统一在故事层；已有大纲、稿件覆盖保留兼容并说明实际来源，不增加逐条混搭版本。
- 世界以可编辑草稿和不可变发布版本区分。条目采用常见内置类型和自由条目，支持别名、标签、关系；不建设任意自定义字段系统。
- AI 与作者通过讨论及条目编辑协作。补充空白可直接进入工作草稿；改变已有内容先形成可审阅提案，采纳、发布和小说升级是独立动作。
- 实现可选的最终整合：将已知设定整合为世界概览提案，作者采纳后进入草稿，不覆盖来源条目，不自动发布。
- 先完成时间线。地图编辑器、自动地图、复杂历法计算暂不进入本专项。
