# AINovel 后续工作路线图

更新时间：2026-09-09。本文是后续开发状态、顺序、门槛和待决策事项的唯一权威入口。代码与当前接口文档仍是实现事实来源。

## 状态定义

- `已完成`：代码、迁移、文档和约定验证已交付。
- `待技术验证`：代码与文档已实现，但按开发者约定暂停，尚未执行测试、构建、部署或运行时验收。
- `验收中`：已开始约定验证且部分检查通过，但仍有明确的未完成项或外部环境阻塞；不得按已完成交付。
- `待运营验证`：功能已交付，但必须先积累真实数据。
- `门槛后立项`：指标达到前不得开始实现。
- `已确认后续`：方向已确认，仍受前置阶段阻塞。
- `独立排期`：不依赖主线门槛，可单独立项。
- `长期储备`：只有数据、模型或商业条件满足后才评估。
- `待决策候选`：仅保留证据，不代表承诺。
- `延迟完成`：需要大量人工收集、标注、评审或持续运营投入；除非用户主动点名，不进入执行队列。

状态：`验收中`

- 新主线目标：有持续记忆、能解释叙事问题、由作者决定取舍的小说创作工作台。长期设计见 [H 系列方案](planning/narrative-harness.md)，首期实现与验收契约见 [H1 开发方案](planning/narrative-h1.md)。

- 保存、重新生成、回滚、合并、删除和重排使来源或已记录输入依赖失效；保留历史原文及审阅。新分支从空账本开始，合并不自动导入状态。
- H1 不向正文生成注入账本，不实现人物知情过滤、完整因果推理或自动改稿。完成约定的 L2 与真实 SSO、AI、桌面/窄屏 L4 前保持 `验收中`；外部阻塞不能用模拟结果替代。
- 已完成 L2 检查：Windows 标准入口后端 336 项通过、12 项条件跳过（外部 MySQL/Testcontainers 与另行授权的付费质量回归），H1 专项 22 项包含在通过项内；前端 lint、类型检查、生产构建通过，全量 34 个文件、136 项测试通过。最后一轮前端标准入口的测试阶段进程停滞，停止后以 `corepack pnpm@11.22.0 run test --maxWorkers=2 --pool=threads` 重跑同一全量套件取得通过结果。发布迁移执行器的四项测试、V15 清单与运行时契约静态检查通过。前端本机使用 Node 24.13.0，与仓库声明的 22.23.2 存在版本差异，保留此验证环境限制。
- Windows 标准入口已启动前后端并通过回环监听/健康检查，现有本地库的 Flyway V15 已执行成功。真实 HTTPS 入口拒绝连接，网关预检读取受保护 Nginx 可执行文件时被拒绝；真实 SSO、AI 和桌面/窄屏操作链尚未验收，已使用真实抽取调用 0/6。
- 隔离的 V1 → V15 与 V14 → V15 验证已尝试，业务账号无临时库 `CREATE DATABASE` 权限，两例均在创建临时库前失败，未创建验证库。须使用具备临时库创建/删除权限的专用验证账号，不能以本地现有库升级代替空库验收。

### H2–H6：按里程碑推进

状态：`已确认后续`，各期以前一期完成为前置，不预设日历日期。

| 阶段 | 交付能力与完成标准 |
|---|---|
| H2 人物认知与上下文隔离 | 区分世界事实、人物认知、正文披露、读者假设、作者计划和作品叙事约定；人物与盲读截止位置隔离测试通过后接入现有单候选生成 |
| H3 多次兑现伏笔 | 独立线索与兑现关系、必要前提、物件可用性、旧细节再利用；局部兑现不关闭其他用途，不能伪造前文属性 |
| H4 逻辑审稿与修订影响 | 知情越界、简单反例、误会核验、结论超出证据及跨章依赖；附原文、成立前提和最小修复，允许不可判断与未发现 |
| H5 人物驱动的规划与编辑 | 根据正文滚动规划动机冲突、参与者、事件余波和成长证据；软建议可拒绝，锁定段落受保护，修订调用有上限 |
| H6 长篇摄入与扩展体验 | G3/G4 共用摄入与证据状态基础，长篇检索、风格资产、文化素材、分阶段读者模拟；覆盖二十章及五十章间隔，模拟与真人数据分开 |

H2 起记录知情越界、矛盾和误报；H3 起记录提前或遗漏兑现；各期记录作者采纳、修订耗时和真实调用成本。模型评审仅作为辅助证据。

### 固定管理员 TOTP 认证加固

状态：`已完成`
