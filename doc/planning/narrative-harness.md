# 作者主导的小说工作台：H 系列设计

本文记录已确认设计，排期与状态只看 [路线图](../roadmap.md)。复用场景编辑器、版本分支、上下文编译器、Lorebook、异步任务和生成反馈，先建立“正文证据 → 作者确认 → 修改失效”，再扩展认知、伏笔和审稿。研究不能直接证明中文长篇质量。

## 里程碑

| 阶段 | 设计边界 | 可独立验收的结果 |
|---|---|---|
| H1 | P11 状态候选与 P13 来源失效；不接生成 | 作者逐场确认、审阅、入账、定位历史证据、复核失效记录 |
| H2 | P01 叙事约定、P03 有限知情、P12 截止位置 | 世界事实、人物认知、正文披露、读者假设和作者计划分开；隔离测试后接入单候选生成 |
| H3 | P06 多次兑现、P14 旧细节再利用 | 线索载体与兑现关系独立，逐条检查物件与已披露属性 |
| H4 | P07 反证审稿、P13 跨章影响 | 原文、成立前提、替代解释、最小修复；允许未发现与不可判断，作者决定改动 |
| H5 | P02 滚动规划、P04 参与者、P05 场景契约、P08/P09 生成编辑、P15 余波成长 | 计划随正文更新、人物动机可追踪、风格与锁定文本受保护、调用有上限 |
| H6 | P10 文化材料、P12 分阶段读者、G3/G4 共用摄入 | 分章摄入、长篇检索与作者资产；二十章及五十章间隔的实际测试 |

G2 真人盲测保留为运营验证；完整方案 A 的四项门槛、G1-A P1/Manual 前置、旧事项未完成验收与 G6 延迟状态均保留。任何自动评审、模拟读者或自评不得充当真人票数。

## 评估与参考

H2 起持续记录知情越界、矛盾、误报；H3 起记录提前或遗漏兑现；每期记录作者采纳、修订耗时、模型与实际费用。离线程序测试、真实模型语义错误与人工修正、真人读者反馈分别记录。模型评审不能独立证明作品无漏洞。

研究输入包括 [DOME](https://aclanthology.org/2025.naacl-long.63/)、[Novelcrafter 按进度资料](https://www.novelcrafter.com/help/docs/codex/progressions-additions)与 [FlawedFictions](https://arxiv.org/abs/2504.11900)。本文沿用已确认方案中的参考，不把参考产品或实验结果视为本产品能力证明。
