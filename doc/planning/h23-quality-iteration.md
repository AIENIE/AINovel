## 作者确认创作边界后的续行 — Plan 1: Direct implementation

允许普通动作、环境、感官和对白细节；关键事件行动者、获知来源、重要往事与身份设定必须有作者批准依据。未提供不是人物一定不知道，也不许可模型补造来源。不要求逐句建账。

在人物可用表述内增加可选 eventActor、acquisitionBasis，作者侧显式填写和确认；只投影这一安全表述，不复制作者说明、原始引文。旧记录缺省为空，编译输入明确标记尚未提供；信念中的行动者和依据仍属于信念，不能变成事实。沿用 JSON 修订存储，不新增迁移。抽取仅提出建议，绝不自动确认。上下文版本升为 v4，长度修正继续复用完整冻结输入。

先冻结 boundary-v4/baseline-v3-source.zip、编译类和四个新独立案例，再修改实现。旧失败案例定向回归在先；独立对照最多 16 次（四例 × v3/v4 × FAST/CRAFTED），占原对照额度剩余部分，额外开发复验从 H2/明确缺陷储备支出。每批不超过 10 次，连续三次同类失败停止路径；独立结果出现后不继续调提示词并称为独立通过。整个 run 沿用 35/200 计数，无新预算。

自动化覆盖旧记录兼容、可选字段往返、作者备注隔离、来源类型保持、上下文预算不足阻断，以及既有重试与冲突链。真实调用先检验开发失败项，再决定是否进入独立组；保存所有结果与完整请求。仅这些新案例通过仍不代替原 H2 全部门槛或 H3 验收。
