## 页面职责与主要功能

| 页面 | 主要功能 | 不承担的职责 |
| --- | --- | --- |
| 创作首页 | 查看项目统计，进入小说或世界观 | 不直接编辑正文 |
| 小说管理 | 项目列表、创建、进入、删除 | 不维护章节正文 |
| 故事设定 | 标题、简介、类型、基调、状态、世界观和角色 CRUD | 不替代世界编辑器 |
| 大纲编排 | 多大纲选择、新建/删除、章节场景、世界观覆盖、AI 生成下一章 | 不保存正文稿件 |
| 正文写作 | 多稿件选择/新建、场景编辑、保存、快速/精雕生成、G2、版本、分支、导出 | 不管理全局素材审核 |
| 素材库 | 当前用户素材 CRUD 与 TXT 异步导入 | 平台审核、查重和合并只在管理员后台 |
| 素材检索 | 写作时检索可用素材片段 | 不修改素材原文 |
| 知识库/图谱 | 故事上下文条目与实体关系 | 图谱删除节点会同时删除 Lorebook 源条目及关系 |
| 质量分析 | 场景、章节、全稿和长篇风险 | 不替代正文编辑 |
| 管理员素材治理 | 审核、重复候选、合并、引用查询 | 不直接编辑用户稿件 |
| 管理员积分 | 直接加发、兑换码、订单和流水 | 不支持从页面撤销已发积分 |

## 推荐操作路径

1. 登录后进入创作首页；新用户优先使用引导创作，已有明确设定时使用传统新建。
2. 在“故事设定”维护类型、基调、角色和已发布世界观关联。
3. 在“大纲编排”显式创建或选择大纲，编辑章节场景；需要时确认积分后生成下一章。
4. 在“正文写作”显式创建或选择稿件和场景，手写或选择快速/精雕生成；保存后再做质量、版本、分支和导出。
5. 素材、知识库和图谱作为写作工具使用，不打断主流程；平台治理操作集中在管理员后台。

工作台使用可恢复 URL：

`/workbench?tab=writing&storyId=...&outlineId=...&manuscriptId=...&sceneId=...`

旧 `id` 参数仍可进入故事，页面会规范为 `storyId`。工作台、素材和设置标签均写入 URL，支持刷新、分享和浏览器前进/后退。

## 响应式安排

- 桌面端保留大纲树、正文编辑区和右侧工具面板。
- 窄屏使用大纲、编辑、参考三个面板；顶部可选择故事、大纲和稿件。
- 移动编辑区提供保存、快速/精雕生成和 G2 投稿；版本、导出和剧情检查位于“参考”。
- 提示词、复杂布局和高级 v2 接口仍更适合桌面端，但不会阻断移动端核心写作闭环。

## 已知限制

- G2 评审保持邀请制，不作为普通导航的公开活动大厅；无有效邀请时页面应给出可操作说明。
- 导出任务和下载地址保留 24 小时，过期后需要重新创建。
- “角色变化分析”和“素材自动提示”已有后端接口，但当前没有独立用户入口，不能按已交付页面功能宣传。
- 高级工作台面向调试和高级配置，可能需要手动输入实体 ID，不是普通创作必经步骤。
- 管理员直接发放积分只支持加分；验收和运营发放必须填写可审计原因。

- 仅记录当前结构和仍然存在的限制；已修复问题通过 Git 历史追溯，不保留另一份日期化问题快照。
- 后续优先级、G2 门槛和延期阶段只在 [roadmap.md](../roadmap.md) 维护。
