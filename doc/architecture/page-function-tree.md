# 页面与功能树及当前体验问题

更新时间：2026-08-03。本文件是 AINovel 当前页面、功能归属和体验问题的工程事实说明；面向创作者的逐步操作仍以 [user-doc](../../user-doc/README.md) 为准。

## 证据边界

- 路由和功能以 frontend/src/App.tsx 及对应页面组件为准。
- 普通用户页面已在 https://localainovel.testhut.top 进行桌面和 390px 窄屏走查；本次是页面与交互结构审查，不是完整的写操作或付费流程验收。
- 管理员业务页受独立 TOTP 认证保护，本文件只记录代码确认的页面职责，不将其表述为已完成浏览器验收。
- doc/test/ 下的日期化问题记录是历史快照。旧问题若已在 doc/operations/verification.md 中复验通过，不应被本文件重新标为当前故障。

### 创作工作台

工作台路由使用 /workbench?tab=标签名&id=故事 ID。前四项是主创作链路，后五项是创作辅助或高级能力。

| Tab | 作用 | 主要操作 |
| --- | --- | --- |
| 故事构思 | 从灵感形成可用的叙事方向 | 创意、类型、基调、秘密和梗；结构骨架、双轨反转、伏笔链；应用到大纲。 |
| 故事管理 | 维护当前故事的基础设定 | 编辑故事信息、查看/新增角色卡、关联世界观、删除故事。 |
| 大纲编排 | 将故事落到章节与场景 | 大纲、章节、场景；目标、冲突、信息释放、伏笔和反转标签；AI 润色。 |
| 小说创作 | 正文写作与场景级工具 | 场景树、富文本编辑、保存、自动保存、快速/精雕生成、质量检查、版本/分支、导出、统计、目标和 G2 投稿。 |
| 素材检索 | 创作中的即时资料查询 | 关键词/语义检索素材片段。 |
| 知识库 | 维护故事上下文 | Lorebook 条目 CRUD、JSON 导入、上下文预览、实体审核、同步图谱。 |
| 知识图谱 | 查看和维护实体关系 | 节点/子图查询、刷新、布局重置、关系增删和节点删除。 |
| 质量分析 | 章节、全稿与长篇风险检查 | Beta Reader、长篇 drift、连续性检查、异步任务、报告和问题状态。 |
| v2 工作台 | 高级接口联调 | Lorebook、风格画像、分析、版本、导出、模型、布局和写作会话的原始接口调用与返回。 |

桌面正文编辑器的右侧工具包括 Copilot、上下文、剧情、版本、导出、统计和目标。移动端是简化视图，只保留大纲、编辑、参考及部分右侧能力。

## 推荐创作顺序与功能边界

1. 从 Dashboard 或小说管理创建项目；新用户优先使用引导创作，已有明确设定时使用传统新建。
2. 在故事构思、故事管理和世界编辑器中完善故事卡、角色和世界观。
3. 在大纲编排中建立章节和场景，再进入正文创作。
4. 写作时使用素材检索、知识库和知识图谱补充上下文；使用场景级剧情面板处理即时问题。
5. 在完成章节或全稿后使用质量分析、版本和导出；账户积分和系统偏好不应打断主创作链路。

职责应按下列边界理解：

- 小说管理负责项目列表、进入和生命周期；工作台的故事管理负责当前故事内容与角色设定。
- 素材库负责全局资料 CRUD/导入；素材检索负责写作时选择上下文。
- 正文右侧剧情工具面向当前场景；质量分析面向章节、全稿和长篇级风险。
- v2 工作台是高级接口面板，不是普通创作的必经步骤。

## 当前体验问题

以下项目是 2026-08-03 代码和浏览器走查中确认的当前问题。处理方向是设计建议，不构成已批准的路线图或开发排期。

| 编号 | 优先级 | 证据 | 现象与影响 | 建议处理方向 |
| --- | --- | --- | --- | --- |
| UI-01 | 高 | 代码 + 浏览器 | 定价页三个 CTA 没有事件或跳转，首页和普通用户导航也没有定价入口，商业转化链路中断。 | 为 CTA 绑定明确的注册、订阅或联系流程，并在首页加入定价入口。 |
| UI-02 | 高 | 代码 + 浏览器 | 普通用户素材库显示审核台，而管理员另有素材治理页；待审查询返回 500 时，页面被错误显示为空队列。 | 明确个人审核与平台治理的权限模型；移除不应暴露的操作，并为失败、重试和空结果分别建模。 |
| UI-03 | 高 | 浏览器 + 代码 | 390px 下工作台内容横向溢出；移动菜单缺少设置和个人中心，正文写作也缺少完整的保存、生成、G2、上下文、统计和目标能力。 | 先消除横向溢出并补齐导航，再为移动端明确保留能力或提供桌面端引导。 |
| UI-04 | 中 | 代码 + 浏览器 | 工作台和设置只在首次读取 tab 参数，切换 Tab 不更新 URL；素材库完全不读取 tab 参数。刷新、分享、前进/后退均无法复现当前视图。 | 让 Tab 状态与查询参数双向同步，并保留 storyId 等上下文。 |
| UI-05 | 中 | 代码 + 浏览器 | 首页已登录用户进入 Dashboard，而无 next 的统一登录默认进入工作台；Dashboard 又没有普通工作台的全局导航。 | 统一登录后默认落点和导航壳，或把 Dashboard 改为含最近项目和继续写作的统一首页。 |
| UI-06 | 中 | 代码 + 浏览器 | 工作台将四个主创作阶段、四类辅助能力和 v2 接口联调并列为九个一级 Tab；v2 需要手填 ID 并显示原始 JSON。 | 分为主流程、创作辅助和高级/调试入口，将 v2 从普通用户主导航移出。 |
| UI-07 | 中 | 浏览器 + 代码 | 小说管理/故事管理、素材库/素材检索、场景剧情/全稿质量分析存在合理但不明显的职责重叠。 | 使用项目管理、故事设定、写作上下文、场景质量、全稿质量等命名和就地说明消除歧义。 |
| UI-08 | 中 | 浏览器 + 代码 | G2 评审没有普通用户全局入口，移动正文也没有投稿入口；无效活动 ID 会直接显示原始英文服务错误。 | 保持邀请制前提下补充待办入口/说明，并将服务失败映射为本地化可操作错误。 |
| UI-09 | 中 | 浏览器 + 代码 | 传统新建有两个同义入口；AI 辅助初始化默认开启但成本提示不明显。 | 合并同义入口，明确关闭后的空项目行为和启用 AI 时可能产生的积分消耗。 |
| UI-10 | 中 | 代码 + 浏览器 | 世界编辑器的预检/发布共用一个按钮：无待生成模块时会直接发布，只有需生成模块时才确认。 | 将预检结果、发布确认和生成发布明确分步，始终让用户确认最终发布。 |
| UI-11 | 中 | 代码 + 浏览器 | 素材列表空数据、工作台未选择故事/大纲/稿件、审核接口失败和 G2 服务失败的引导/错误态不一致。 | 为空数据、前置条件不足和服务故障分别提供说明、下一步和重试入口。 |
| UI-12 | 低 | 浏览器 | 桌面正文右栏使用 copilot、context、plot、version、export、stats、goals 等英文内部名称，与中文界面和移动端标签不一致。 | 统一中文术语和图标提示。 |
