# Slop 第二轮：表达质量多路线研究

日期：2026-09-26。基线：`3678b7a772d9916ac26bd74129098cb01c90d17f`。本事项只交付研究工具和文档；业务规则、阈值、数据库迁移、产品提示与自动采纳均未修改。最终费用/调用数以 `integrity.json` 和 `experiment-calls.json` 对账为准。

实际 **28/40次调用、28项目积分、0次模型重试**。10次生成、12次编辑、6次复核；8项按停止规则跳过，4次故障备用未用。详见[真实对照汇总](experiment-summary.md)。

## 研究判断

不能把“扩规则、提高风险分数敏感度、多改一次”当默认答案。需要同时解决来源/差异可信、上游场景授权、画像真实性与作者控制。现有精雕提示和风格卡组合都在前两个悬疑任务中补造了关键依据，触发停止；风格卡让描写具体并不等于情节更可靠。正向目标也有幻想剧情越界，不能直接取代现有提示。

编辑对照没有证明段落重组优于最小补丁：前三份自然原稿主要得到细小语法修改；受控尾注案例是声音与精简的取舍，动作重复案例甚至保留模板而擅改含混否定。模型复核看见这个diff仍以“疑似错字”放行，说明完整差异是必要条件而非安全证明。建议暂不进入新改写功能实现；后续先完善共同基础设施与真实作者标注，再修订授权细节/弃判契约做独立验证。

本轮将硬内容和软表达分开：普通动作、环境感官可以补充；关键事件、重要经历、人物知情、否定、线索及意图不得擅改。删光标闪烁等停顿可以讨论，人物声音另评。对“膝盖旧伤”是否已构成重要经历保留 uncertain，而非借宽泛安全理由判一切新增细节失败。

## 与第一轮结论的关系

第一轮24条片段仅为历史回归，不再称未知留出。原先“明显问题多来自构造片段”仍是数据限制，不是中文小说问题分布的结论。第一轮诊断偏风险、修订偏删句；本轮两个编辑提示统一针对表达作用，并允许不改或只反馈。原来删除任何细节容易导致复核失败，本轮改用分级保留；模型复核仍需独立校准和完整差异检查。

统一全文抽取、坐标、版本和覆盖的必要性不因路线拓宽而消失；“解决这些即可自动安全改稿”的推论不成立。是否改、改到何种粒度，以及声音得失，需要独立质量证据。

## 实验设计及边界

- 独立 run `slop2-20260926-v1`，持久化上限40；计划36，4次仅故障备用。没有沿用第一轮或H2预算，没有因结果不好调提示重试。
- 6个冻结生成任务覆盖悬疑、日常关系、幻想各2个，均为代理编写场景上下文；模型输出是真实调用，不冒称用户作品自然续章。三臂现有精雕/移除禁用块/再加代理风格卡和示例使用同内容及550–750汉字目标。系统剩余负面指令没有消失。
- 生成请求经生产 `PromptAssemblyService` 组装，实际调用本地认证 API 和 ai-service；未调用稿件生成落库端点，不经过产品长度重试。未达长度目标计入结果，不额外付费补齐。没有运行时模型版本和采样seed保证；实际模型由服务器策略固定为deepseek-flash。
- E1/E2/E3 分别为旧S2/S5/S6原稿；E4/E5/E6在同源原稿末尾人工加入对白尾注/拿起放下/抽象总结。它们不是6个独立自然作品；比较可揭示同源编辑差异，不能估计总体效应。
- 两个编辑臂都允许空patches，段落臂先说明目的，最多2整段；最小臂最多4处。确定性应用核对唯一引文、UTF-16位置、重叠及段落范围；非法则保留原稿并记录，不自动“修JSON再试”。
- 代理先完整阅读原稿与修改并冻结自己的判断，再请求模型同时复核匿名A/B及完整diff、冻结问题和一个校准片段。A/B顺序按奇偶轮换，评审模型与生成模型相同，不称真正独立评审。
- 同臂两次相同关键破坏停止，保留缺失单元和停止原因，不用剩余预算挑优；所有输出只写研究产物，不覆盖小说正文。

## 复核与复现

`scripts/research/slop2-freeze.py` 仅创建冻结数据，存在freeze时拒绝覆盖。`Slop2Prompts.java` 调生产提示组装。`slop2-offline.py` 是只读业务、无模型调用的结构观察原型；`baseline-results.json` 由第一轮的Java `SlopStudy` 调现有本地规则生成。运行环境与依赖复用既有后端构建产物，不作为发布产物入库。

`slop2-client.py` / `slop2-session.py` 是经批准的本地研究客户端：SSO密码仅内存，TLS正常验证，每行显式派发一调用，固定run、幂等key和数据库预算；不存在自动批量重试。外部实验env与登录令牌不入库。**本run已使用，不能重新seed或删除预算后重跑。**重新付费实验须新授权和新run。

`slop2-package.py` 导出白名单字段并核对冻结数据、标签平衡、来源分组、预算/积分、UTF-16应用与代理先读时间。`freeze.json` 使用原始文件字节哈希；protocol的hash继承prepare的文本哈希（通用换行归一），两者定义不同且分别验证。最初打包校验发现这一区别后只修验证器，不改冻结输入；这是离线工具校验修复，不计模型故障重试。

本轮所有评分都是代理或模型评审；不计入G2真人盲测，不宣布统计显著，不宣布H2完成，不启动H3/H4、多候选竞技场或题材分库。作者操作负担、长期趋同、跨模型效果与训练收益仍待真实作者数据。
