# 一手文献证据表

检索/核对日期：2026-09-26。下列为原论文，不用营销文章推导效果。论文结果是方法证据，不是 AINovel 中文小说的效果保证；本轮没有复现训练、NLI 或 QA 模型。文献中的评价规模不能移作本实验的样本量。

| 来源 | 可支持的判断 | 不能推出的判断 / 接入含义 |
|---|---|---|
| [Whose story is it?](https://aclanthology.org/2025.ijcnlp-long.82/) | Mythos 含约 3.6k 故事、112 作者；从作者历史作品提炼 Author Writing Sheet，再引导生成；风格贴合有改善，情节个性化更难。 | 代理写三张风格卡不是作者画像。需真实、获授权、跨场景作者样本和作者确认；本轮仅检验示例控制，不证明中文个性化。 |
| [Help Me Write a Story](https://aclanthology.org/2025.acl-long.1254/) | 1,300 份受控破坏故事用于检验反馈；模型常能给具体意见，却会漏掉最大问题或误判何时批评。 | 反馈多不等于有用；受控问题命中不能当真实问题发生率。需要“不需修改”与优先级标签、作者采纳成本。 |
| [QAFactEval](https://aclanthology.org/2022.naacl-main.187/) | 问答生成、可回答性判断影响事实检查；QA 与蕴含信号可互补。 | 摘要方法不能直接裁决中文小说隐瞒、谎言、视角和潜台词。先冻结问题及证据范围，区分作者事实与人物信念；本轮只借鉴问题核对，未运行 QAFactEval。 |
| [SummaC](https://aclanthology.org/2022.tacl-1.10/) | 句子级 NLI 与文档级事实任务存在粒度差异；分段并聚合能改进一致性判断。 | 单句蕴含不能证明人物意图和跨段线索未变；需双向检查删除与新增，并验证中文否定、模态和实体归属。本轮未部署 SummaC。 |
| [Modifying LLM Post-Training for Diverse Creative Writing](https://arxiv.org/abs/2503.17126) | 以多样性为目标修改偏好后训练可改变质量/多样性取舍；数据和损失设计重要。 | 当前几十份代理样本不足训练可靠编辑器；不能把词汇稀有性当文学质量。需高质量偏好对、许可、独立作者留出和训练/回归成本。 |
| [Verbalized Sampling](https://arxiv.org/abs/2510.01171) | 显式请求响应分布是缓解模式塌缩的一种提示方法；研究讨论典型性偏差。 | 多候选和概率文字会增加 token/延迟，弱模型收益不保证；概率不是可靠质量或事实置信度。本轮不开展产品竞技场，也没有额外抽样挑优。 |
| [CoEdIT](https://arxiv.org/abs/2305.09857) | 指令编辑可由专用训练模型承担，不必始终依赖通用大模型整篇重写。 | 通用编辑任务成绩不代表中文小说声音保留；需要目标语言和最小补丁能力的独立验证。 |
| [mEdIT](https://arxiv.org/abs/2402.16472) | 多语言编辑是可研究的专用模型路线。 | 本轮未确认对本系统中文小说的有效覆盖、部署许可和硬件收益，不列为已可接入替代品。 |
| [GhostWriter](https://arxiv.org/abs/2402.08855) | 将用户风格与创作控制权作为协作写作问题研究。 | 不能用模型替作者决定“像不像我”；接受/拒绝需记录理由，保护表达可撤销，作品偏好不可无条件跨作品迁移。 |
| [The Curious Case of Neural Text Degeneration](https://arxiv.org/abs/1904.09751) | 解码方法会改变退化与重复；概率截断是独立于提示的研究维度。 | 提高随机性不自动改善剧情、事实或句式；本接口未暴露相关参数，不能声称温度/seed 已固定。 |
| [文本风格迁移评价研究](https://aclanthology.org/2024.lrec-main.1373/) | 支持将风格变化、内容保留、流畅性分开研究。 | 不将一项风格分数当总质量，不直接移用其阈值。小说还需人物声音与叙事意图。 |
| [G-Eval](https://aclanthology.org/2023.emnlp-main.153/) | 模型评审具有实用性，也需要考虑评价偏差。 | 同模型复核不是独立真值；完整 diff、校准错误、代理先读仍不能替代真人盲测。 |

证据等级：本库代码与逐例结果为直接但局部证据；同行评审论文为外部方法证据；arXiv 训练/采样路线为候选研究证据；作者负担、长期趋同和中文迁移效果尚未获得本地实测。
