## 数据与方法

[freeze.json](freeze.json) 固定了样本/场景文件哈希、代码基线、模型和 20 次上限。文件哈希按 UTF-8 JSON 文本的 LF 归一化计算，正文哈希按解析后的原始字符串计算；校验器最初误用 Windows 文件字节导致失败，改为与冻结生成器一致的口径后校验，未重冻或改样本。[samples.json](samples.json) 为六类各四例，合计 12 正/12 反；16 个开发样本、8 个留出样本，来源明确为真实模型片段或代理构造。标签表示“是否值得句式干预”，不表示是否由 AI 写作。开发集 10 正/6 反，留出集 2 正/6 反，不均衡且很小。F10 等标签可争议，不能当真人金标准。

[scenes.json](scenes.json) 冻结六份真实输出：S1/S2/S3 来自快写第一、二、四场；S4 为精雕开篇；S5/S6 来自 H2。分组是抽样意图，不预判最终有问题。完整阅读另覆盖快写其余三场，共 9 份，见 [reading-corpus.json](reading-corpus.json)；补充阅读材料没有用于调参。精雕其余五场未生成，未伪造对照。

离线适配器直接调用当前 `LocalSlopHeuristics` 及匹配器，不复制一套规则。记录 raw hits、问题、风险、SHADOW 和付费复核触发位；本轮未调任何规则或阈值。以 `requiresAiReview` 为分类触发定义：

| 样本集 | TP / FP / TN / FN | 精确率 | 召回率 | 准确率 |
|---|---|---:|---:|---:|
| 全部 24 | 5 / 0 / 12 / 7 | 100% | 41.7% | 70.8% |
| 开发 16 | 5 / 0 / 6 / 5 | 100% | 50% | 68.8% |
| 留出 8 | 0 / 0 / 6 / 2 | 不可定义（无阳性预测） | 0% | 75% |

这不是生产准确率估计。5 个命中均为人工构造的典型高密度片段，7 个漏报覆盖同义尾注、改换宾语的动作、抽象升华与停顿骨架。本样本未触发误报不代表不存在误报；F04 的合理推理仍有风险 28 的弱提示。真实 9 场全部零风险，模型与代理仍发现可争议编辑点。新增结构特征应先记录证据，不能据此直接转 ACTIVE。

## 已复现的工程问题

结果见 [baseline-probes.json](baseline-probes.json)，探针源码见 `scripts/research/SlopProbes.java`。均为本次执行，0 模型调用。

| 探针 | 观察 | 后果与优先处理 |
|---|---|---|
| 10-gram 重复串前加一个字 | 原风险 68；加“序”后不命中 | 固定步长对相位敏感，漏报不等于无重复 |
| 相同机械否定串加全局“侦探分析腔；排除法” | 风险 72 → 28，关闭复核触发 | 上下文例外须落到局部信息增量，不能整场免责 |
| 原文前置两个空格 | 报告仍指向 trim 后 start=1；调用者原文应为 3 | 必须统一正文抽取和 UTF-16 位置 |
| 假引文且位置 999..1000 | 解析器保留不存在于“他走了。”的证据 | 入库/高亮/改写前必须逐字验证 |
| 同一句出现两次，无坐标 | 回退到第一次出现 | 多重匹配不能自动定位 |
| 高风险长文替成“他走了。” | `isSaferRevision` 返回 true | 本地风险下降不能证明内容保留；只是接受谓词反例，不声称真实模型本次生成过这种删稿 |
| 7100 字后尾哨兵 | 诊断/评审/整稿修订提示均不含尾部 | 5000/7000/6000 截断导致漏检或丢尾风险，须分块并记录覆盖率 |

这里的“长文”是用于隔离截断问题的构造文本，不计作真实小说样本。建议优先修来源位置与覆盖，再做补丁化与审阅 UI，最后验证自动采纳。

## 评估边界与结论

句式改善、内容保留与流畅度分开记录，参考 [文本风格迁移评估研究](https://aclanthology.org/2024.lrec-main.1373/)。模型评审只作证据之一，[G-Eval](https://aclanthology.org/2023.emnlp-main.153/) 的评审偏差提醒也适用为方法风险，但两项研究均不能直接证明当前中文小说任务的效果。

本次固定 deepseek-flash，应用策略解析 modelId=null，账本逐次确认实际模型；网关 temperature/top-p 与底层模型版本未公开，不能承诺逐 token 可复现。提示与顺序在调用前冻结；诊断检查六类形式，但修订提示更窄，只要求改“有证据的句式重复”，这是本批弃改偏多的一项混杂因素，不在批中改提示重跑。单模型自评可能漏看 diff，必须保留独立代理逐字复核以及后续真人验收。

两入口实施方案明确：版本化全文快照、UTF-16 位置/富文本映射、唯一引文校验、局部补丁、覆盖状态、乐观版本冲突、异步任务/计费恢复、旧报告迁移、作者逐项接受/拒绝/撤销、生成一次且失败保留原稿。自动采纳默认关，新增结构信号只离线观察；后续启用须完成 L2 与本地 L4，以及独立真人保留验收。
