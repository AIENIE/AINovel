# 初稿质量定向研究：场景适配目标

日期：2026-09-26。基线 `2ad2b07870ad0ada31c8027515f3fc40ffe9ed62`。结论：**保留生产现状，场景适配目标继续作为研究候选；本轮不建议替换生产提示。**

独立 run `slop3-20260926-v1` 实际 **5/40 次模型调用、5 项目积分**，均为成功首次生成。A 与 B 各出现两例同类关键事实破坏，按调用前冻结规则分别停组。没有重试，也没有花剩余额度寻找更好结果。停止意味着预定规模未完成，不能用这五份结果估计稳定胜率。

## 问题与方法

生产精雕提示按场景序号轮换两条叙事要求，未根据内容选择。A 保留它们；B 只替换“本节叙事质量目标”块为代理离线编写的行动目标与表达目标。两组使用相同模型策略、上下文、禁用项、参考资料和 550–750 汉字目标。具体代码依据、潜在冲突和论文边界见 [冲突审查](conflict-audit.md)。

[8 个冻结任务](tasks.json)、[32 份完整请求](requests.json)、[逐场提示差异](prompt-diffs.md)、[协议](protocol.json)、[协议封印](seal.json)均在首次调用前生成。G1–G6 来自第二轮，明确是历史代理构造回归任务；G7 核证与 G8 日常关系是本轮代理构造，**不是自然作品留出集**。事实、人物意图、未知事项与结束位置在任务 context/intent 中冻结，普通细节授权另列；没有隐藏作者秘密。

原计划 32 次生成、4 次匿名复核、最多 4 次技术故障备用。固定顺序先执行 G1、G3、G5、G7、G2、G4、G6、G8 的第一次，再执行第二次；场景间交错 A/B 先后。每对阅读全文、记录断言及判断后再继续。停止后仍存活的组可继续，缺失对照不计胜负。

实际模型账本均为 `deepseek-flash`；应用实际由模型策略路由，不是任意 `modelId` 自由选择。接口未暴露随机种子、温度等，无法声称控制底层采样。两次独立生成虽已冻结不同幂等键，但由于提前停止，**第二次均未实际执行**。

两个完整配对：G1 收益不确定，G3 判 B 有明确收益，主要是行动主体与意图保持更好。G5 只有 B，不作胜负。**不能写成 B 在 16 对中获胜，或将未运行场景计作平局。**

五个维度分别观察：

- **事实与知情**：两组都新增关键断言，B 的具体目标没有消除这一风险。将未知来人声称的话保持为声称，并不授权任意新增能改变推理方向的证言事件。
- **声音与意图**：G3-B 更好保留主动回避；A 换了提议主体。任务只有简要人物意图，没有自然作者声音样本，无法验证长期声音保持或系统性退化。
- **场景完成**：留联申请、电话安排、敲第二次等总体动作仍可完成，但完成目标与不编造事实不是同一个指标。正文常继续延展到既定行动之后。
- **自然度**：B 两个配对的篇幅较收敛，但 G1 新造调查证据、G5 额外诱敲情节仍有明显设计痕迹；紧凑不能抵消内容失败。
- **节奏与重复**：G3 两组均反复开合、摆放、检查工具盒；B 没有彻底消除填充动作。句长、段数和表层形式计数见 [辅助统计](output-statistics.json)，这些不构成质量分数。

完整配对的长度遵守为 B 2/2、A 0/2；全部已执行 B 为 3/3。分母不同、场景少且无第二次重复，只能描述这批输出，不能推断普遍长度优势。汉字计数排除标点与空白，逐份保留原文哈希。

## 停止、缺失与判定敏感性

- 第 4 次后 A 停组：G1-A1 与 G3-A1 都标为 `new_critical_fact`。
- 第 5 次后 B 停组：G1-B1 与 G5-B1 同类失败；两者也新增人物确定知晓的推理依据。
- 共 27 份生成未运行；预定 4 个复核场景 G1/G3/G5/G7 均没有完整四输出，因此 4 次模型复核跳过。4 次故障备用未用，35 次总额度未使用。逐项缺失原因见 [机器可读汇总](summary.json)。
- [四类校准案例](calibration.json)已冻结，但**没有送模型校准**，不能报告本轮模型判别准确性、匿名复核结论或独立评审一致率。代理记录先于任何模型复核，本轮复核数量实际为零。
- “关键事实”有边界判断：G3 的新通勤路线与展览安排标为不确定，普通胶布、物件整理与寒暄不自动判失败。A 的送菜被视为改变心理组织的新关系事件；若作者认为这是普通可授权补全，A 停组时点需要复议。本轮不事后放宽标签并恢复付费。B 在 G1/G5 的新物证、查账及病史仍是明确风险。

## 对假设的修正

代码确有内容无关的轮换要求，但实验没有证实它是补造事实的主因。B 去掉这些要求后仍编造关键证据与往事；保留原有稳定规则、禁用清单、稀疏任务、长度要求和同一模型，都可能共同影响输出。本轮不能进一步归因到“代价”或“缓冲”一句提示，也不能证明方向无效。

更值得下一轮拆开验证的是：明确哪些事实可以补全、把行动主体与结束状态变成核对项、场景信息量是否足以支撑要求篇幅。风格画像和固定口头禅另行验证。详见 [后续实施建议与验收条件](implementation-advice.md)。这些是假设和候选，不是本轮已验证能力，也没有新增实验授权。
