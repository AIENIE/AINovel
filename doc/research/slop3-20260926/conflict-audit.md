## 固定人物声音

`backend/src/main/java/com/ainovel/app/style/StyleService.java:149` 的 `generateCharacterVoice` 只将输入名字填入固定短句/反问/口语化描述，写入相同的“这事不对劲”“让我想想”，示例也是换名字的同一句线索对白。没有依据角色履历、立场或已有对白生成差异化声音。

这给不同人物注入同一表达偏好，属于明确的同质化风险；尚未通过本轮 A/B 证明真实输出一定复用这些口头禅。作者保存的自定义声音也不能一概说成固定模板。后续可先研究将自动模板标成未确认建议，区分作者指定口头禅与系统填充；本轮不修改声音生成或入库行为。

## H2 与旧路径的风格资料不等价

- `manuscript/context/SceneDraftContextCompiler.java:100`：H2 启用后调用 `NarrativeContextService.preview` 并提前返回，要求存在 PLAN，不执行后面的 `addStyleCandidates`。
- 同文件 `addStyleCandidates`：旧路径读取激活画像、场景覆盖与最多两个相关角色声音。
- `narrative/NarrativeContextService.java`：消费批准记录、知识及 Entry，未读取 StyleProfile/CharacterVoice repository。手工 Entry 可以含风格文字，不等于画像自动投影。其内容与来源过滤不能绕过。
- `manuscript/SceneGenerationPromptBuilder.java:81`：隔离路径将全局标题/类型/文风等替换成中性值、清空素材，使用受控上下文。旧路径仍用故事文风与素材。

因此“旧路径已支持画像”不能作为“H2 正在使用同一画像”的证据。候选最小方向是经来源与秘密检查的风格投影，不能回填旧全量上下文；还需独立验证样例不携带未公开剧情。

## 本研究实际覆盖的路径

研究 Java 适配器调用生产 `PromptAssemblyService` 和规则采样器，使用单场冻结上下文后调用现有 `/api/v1/ai/chat`。它**没有调用完整 H2 preview，也没有运行产品起草的长度重试、异步保存或 UI 流程**。输入 compiler 标记为 `scene-isolation-research-v1` 是研究标记，不能冒充 H2 运行时验收。无隐藏作者秘密输入，场景间不共享上下文。本轮只测首次调用输出；所有超长或不足结果原样保存，不能静默重试来修长度。
