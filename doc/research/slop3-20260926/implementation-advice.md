# 后续实施建议（本轮不实施业务变更）

## 当前决定

保留生产提示。具体场景目标仍是值得继续验证的候选，但必须经过冻结门槛，不以个别更顺畅的段落代替内容保留验收。停止实验后不把余额用于临场调提示找更好的结果。

## 保留的研究基础设施

- 单一场景完整上下文、来源标记、输入/输出 SHA-256、原始响应、实际模型与费用账本。
- 两次独立请求用不同幂等键，传输不明确时只对账与取回原结果；已完成键禁止再次付费。
- 代理全文阅读、逐条关键断言追源与分维度评价；普通描写、轻量安排与关键事实分级，不用单一分数接受文本。
- 保留第一、二轮提出的全文覆盖、UTF-16 位置、版本冲突及局部建议基础设施；本轮未证明其效果，也不引入自动改稿。

## 下一次验证的优先问题

1. **补充事实的授权范围**：将事实写成可引用的条目，另外显式列出可自由补充的普通细节类别。尤其区分可描写纸张外观与不可新造能排除伪造的物证结论、可描写通勤与不可新增影响人物选择的往事。它可能比再加一句“不要编造”更便于模型和评审执行，但尚未验证。
2. **目标密度与篇幅匹配**：小任务要求 550–750 汉字，是否迫使模型用流程、反复动作或回忆补足篇幅？本轮长度不变，不能回答这个因果问题。下一次若试长度，须与目标替换分开，冻结允许范围后再调用。
3. **行为主体与结局约束**：谁主动提出、谁同意、结束时物件在哪，宜成为独立核对项；自然对白不能掩盖行动主体变化。即使最终物件位置相同，人物意图仍可能变化。
4. **风格资料来源**：先核验 H2 实际投影，再研究风格效果。固定口头禅可能是同质化源，不能靠多注入示例解决所有场景；作者指定的惯用语应保留。

这些是后续研究候选，未安排新增预算。当前结果不能同时证明它们有效。

## 若以后通过门槛，最小业务实现形态

现有提示组装的输入内部增加可选 `sceneGoals` 与来源信息（来源任务/计划、版本或哈希、作者/代理标记）。只允许重述已授权任务，两项分别表示行动与表达方式；缺失、不适用或来源失效时回退旧模式。如何由作者确认、是否展示来源、是否提供新产品接口，需届时另行确定。本轮不新增公共 API 或数据库迁移。

不得把不受限的全局故事资料、作者秘密或旧全量风格字符串加入 H2。目标应沿用当前受控场景计划来源，并服从现有人物知情与版本失效机制。若后续需要持久化，先决定能否复用已有计划/版本结构；不能在研究阶段预设新表或迁移编号。

## 后续 L2 / 本地 L4 验收候选

| 层级 | 必须验证 | 启用约束 |
|---|---|---|
| L2 提示与来源 | 仅目标块变化；旧模式逐字回退；Unicode/富文本来源稳定；版本变更失效；目标与场景绑定；空值/超预算拒绝或回退 | 不能截断到半条目标；来源失效不继续使用 |
| L2 隔离 | H2 场景、人物知情、隐藏作者秘密及风格示例分别验证；跨场景请求无污染 | 不以本轮研究标签代替 H2 真隔离测试 |
| L2 异常 | 幂等、预算上限、请求中断、结果取回、费用结算、异步任务恢复 | 不因响应不明重复付费 |
| 本地 L4 | 现有作者入口生成、版本保存、回退旧模式、修改计划后再生成、跨场景切换、失败恢复 | 真实提示、正文及持久化一致，作者能看到效果与局限 |
| 内容门槛 | 完整 16 份 B；零硬失败；16 对中至少 10 对明确收益；至少 6 场景两次不劣且一次更好；声音与长度要求均满足 | 探索性门槛仍不是统计显著，也不替代 G2 真人盲测 |

本轮只验证研究工具和授权的模型调用，不声称完成上述产品 L2/L4。H2 仍按路线图验收，H3/H4 不启动。
